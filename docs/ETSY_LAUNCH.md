# QuietPixelStudio Etsy Launch Kit

## Product position

Pixel Meadow is a paired day-and-night animated wallpaper pack for Apple
Silicon Macs. The approved artwork and motion are final. Its commercial value
comes from coordinated scenes, seamless loops, quiet pacing, static fallbacks,
and optional sunrise/sunset automation.

Use `QuietPixelStudio` if Etsy accepts it. Use `QuietPixelWorks` only if the
first name is unavailable. Use an existing monitored Gmail account with
two-factor authentication; the public shop identity is the shop name.

Launch at **$8.99** and use **$12.99** as the regular price.

## Listing title

Animated Pixel Art Wallpaper for Mac, Day Night Live Desktop, Cozy Meadow Screensaver, 2560x1600

## Listing description

Turn your Mac desktop into a quiet pixel-art meadow that changes with the time
of day. Pixel Meadow includes coordinated daytime and moonlit scenes with slow
cloud and grass motion, seamless 18.5-second loops, silent playback, and an
optional sunrise/sunset switcher designed for the free Aerial 4 app.

### Included files

- Day animated wallpaper: 2560×1600 HEVC MP4
- Night animated wallpaper: 2560×1600 HEVC MP4
- Day and night static PNG wallpapers
- Pixel Meadow Automation installer and uninstaller
- Illustrated PDF setup and troubleshooting guide
- Personal-use license

### Compatibility

- Apple Silicon Mac: M1 or newer
- macOS 15 or later
- Aerial 4 required for animated wallpaper playback
- Playback speed: 1.0x
- Audio: none

The automation is an unsigned shell-script installer, not a notarized Mac app.
macOS may require you to Control-click the installer and choose Open. The
wallpaper videos can still be selected manually without the automation.

### AI disclosure

The source artwork and initial motion were created with seller-directed
generative AI. The seller selected, edited, timed, cropped, slowed, blended,
encoded, loop-tested, and packaged the final wallpaper files.

## Launch gate

- Download and open the package from a fresh macOS user account.
- Confirm the unsigned-installer warning matches the guide.
- Confirm the installer leaves one Pixel Meadow MP4 in Aerial's My Videos.
- Watch three loops without a black flash.
- Confirm the uninstaller preserves both videos in the user's Movies folder.
- Ensure every listing image depicting the product uses exact wallpaper frames.
